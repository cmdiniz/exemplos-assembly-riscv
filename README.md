# exemplos-assembly-riscv
Exemplos de códigos assembly do RISC-V usados na disciplina INF01075 Arquitetura de Computadores, do [Instituto de Informática (INF)](https://www.inf.ufrgs.br/site/) da [Universidade Federal do Rio Grande do Sul (UFRGS)](https://www.ufrgs.br/).

Os exemplos foram testados no [RARS](https://github.com/TheThirdOne/rars/) [v. 1.6](https://github.com/TheThirdOne/rars/releases/tag/v1.6)
